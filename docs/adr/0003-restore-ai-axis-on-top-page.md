# トップページの見出し軸を「システム開発」先頭から「AI開発」へ戻す

cloudnature.jp トップの h1・title・meta description・OG・llms.txt を、「新潟のシステム開発・AIエージェント開発会社」から「新潟のAI開発・AI導入支援パートナー」へ変更する。ADR 0002 がトップに採用した「システム開発 ＋ AIエージェント開発」の2語を撤回する。

## Status

accepted（2026-08-22）

ADR 0002（トップの見出し軸を「AI開発」から「システム開発」先頭へ）をトップページの見出し軸に限り supersede する。ADR 0001（AI導入支援 → AI開発への転換）は supersede しない。トップの主軸が「AI開発」であること自体は ADR 0001 のまま維持し、本 ADR はその次に続く語を「AIエージェント開発会社」ではなく「AI導入支援パートナー」に差し替えるものでもある。

## Context

ADR 0002 は GSC 実測（「新潟 システム開発」系 83imp vs 「新潟 AI開発」系 11imp）に基づき、ブランド一貫性より実需要のある語を優先する判断だった。この判断自体は覆さない。

一方で、ADR 0002 採用後のトップページには次の構造上の問題が残っていた。

- h1「新潟のシステム開発・AIエージェント開発会社」は、「システム開発」と「AIエージェント開発」を並列の2語として提示する。しかし AIエージェント開発はシステム開発の一種であり、上位概念と下位概念を並列に置く構造になっている。
- 本文（ヒーローのディスプレイコピー「AIトランスフォーメーションで／人手に代わる仕組みを実現する」、リード文の「AIを前提として再構築」、SERVICE セクションの「AIエージェント」訴求など）は一貫して AI Transformation 企業としてのポジションを主張している。
- 結果として、「h1 = 普通のシステム開発会社」「本文 = AI Transformation 企業」というブランドの不整合が生じていた。これは検索順位以前に、トップページを読んだユーザー・採用候補・取引先が受け取る第一印象の一貫性を損なう。

## Considered Options

- **A. ADR 0002 のまま維持**。「新潟 システム開発」系のGSC実測需要（83imp）に対応し続けられるが、h1構造の不整合とブランド分裂が残る。
- **B. h1 のみ変更し、title/meta/OG/llms.txt は据え置く**。作業は最小になるが、h1とtitleが別の軸を語る新たな不整合を生み、SERPのスニペットとページ本体で第一印象が割れる。
- **C. h1・title・meta description・OG・llms.txt を「新潟のAI開発・AI導入支援パートナー」に統一する**。← 採用。トップ全体の対外的な自己紹介文言を1つの軸に揃え、本文のAIトランスフォーメーション訴求と整合させる。

## Decision

- トップ h1 / title 系: `新潟のAI開発・AI導入支援パートナー`
- 対象ファイル: `content/home.ts`（`HERO_COPY.badge` / `heroImageAlt`）、`content/common.ts`（`PAGE_META.home`）、`app/layout.tsx`（title / description / OG / Twitter / JSON-LD の Organization・ProfessionalService 記述）、`app/llms.txt/route.ts`
- 「AI導入支援パートナー」は `PAGE_META.company.title`（新潟のAI導入支援パートナー）で既に使われている既存の語彙であり、新規の造語ではない。

### 変更しないもの

- ADR 0002 が同時に決めた「メタデータから『中小企業』を外す」判断は覆さない。本 ADR の対象ファイルでも `PAGE_META.home.description` に「中小企業」は再導入していない。
- `/services/system-dev` の title・description（「新潟のシステム開発会社」軸）は変更しない。「新潟 システム開発」系のGSC需要は引き続きこのページが受ける。トップの軸を変えても、この語自体を手放すわけではない。
- ヒーローのリード文3段落（`HERO_COPY.paragraphs`）、`SERVICES_SECTION.lead` の `/services/system-dev` への文脈内リンクは変更しない。第3段落の「システム開発・AIエージェント開発を通じて」という語順は ADR 0002 以前からの既存文言であり、今回のスコープ外。

## Consequences

- 「新潟 システム開発」の実需要（GSC 83imp/3ヶ月）に対するトップの直接対応は再び弱まる。ただし `/services/system-dev` が引き続きこのクエリ群のOwnerであるため、需要そのものを手放すわけではない。
- ADR 0001・0002・0003 と軸の変更が続いており、再転換のたびにSEOシグナルの再構築に数ヶ月かかる。次に軸を変える判断をする前に、今回の変更を最低3ヶ月は維持し、GSC実測で効果を確認すること。
- 本変更はブランドの一貫性（h1と本文の整合）を検索需要データより優先した判断であり、ADR 0002が明示的に退けた Option A の再評価にあたる。将来再度「システム開発」を軸に戻す場合は、本ADRのブランド不整合の論点に対する具体的な解決策（例: 「システム開発」を上位概念として本文側も書き換える等）とセットで検討すること。
