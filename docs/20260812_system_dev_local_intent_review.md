# 「新潟 システム開発」SEO差分レビュー

## 検証目的

`main` と `seo/system-dev-local-intent` の差分について、虚偽表示・誇大広告・会社ブランドを損なう表現がないか確認する。

## 対象範囲

- `main...HEAD` の変更ファイル
- 変更された公開文言と、その根拠となる既存コンテンツ・会社情報

## 確認項目

- [x] 実績・能力・地域性などの事実主張に根拠があるか
- [x] 優良誤認や断定的な成果保証につながる表現がないか
- [x] サービス内容と遷移先ページの実態が一致するか
- [x] CloudNatureの既存ブランド方針・トーンと整合するか
- [x] SEO目的の反復や不自然な地域キーワードが信頼感を損ねないか

## 検証結果

### 要修正

1. `content/services.ts:118,133`
   - 「既存のシステムを使い続けたまま」「いまお使いのシステムを止めずに」は、対象システムのAPI・契約・構成を確認する前の無条件な保証に読める。
   - 既存FAQの「API連携やデータベース連携で対応」という提供方針より主張が強く、実案件で停止や移行が必要になった場合に期待との齟齬が生じる。
   - 「既存環境を活かし、可能な範囲で業務への影響を抑えながら」など、技術調査を前提とする表現が安全。

### 軽微な改善候補

1. `content/common.ts:89`
   - meta description冒頭の「新潟のシステム開発会社。」は検索語を置いた断片文に見え、自然さ・専門会社としての品位がやや弱い。
   - 「新潟市を拠点に、〜を手がけるシステム開発会社です。」のような一文にすると、SEO意図を保ちつつ自然。

### 問題なしと判断した点

- 「新潟市中央区を拠点」は会社概要の所在地と一致する。
- システム開発、Webアプリ、業務自動化、AI組み込み、保守運用は既存の事業・サービス説明と整合する。
- 新しい導入社数、成果数値、顧客名、優位性比較、No.1表示、成果保証は追加されていない。
- 記事内リンクの追加は文脈に沿っており、会社の提供サービスを不自然に水増ししていない。
- 地域名の追加はH1・title・説明文が中心で、可視本文に過剰な反復はない。

### 総合判定

重大な虚偽表示や典型的な誇大広告は確認できない。ただし、既存システムを無停止で維持できるかのような2箇所は、案件条件に依存する内容を断定しているため、公開前の修正を推奨する。
