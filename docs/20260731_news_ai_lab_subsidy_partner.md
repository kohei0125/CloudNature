## API 経由での自動作成を試した結果（2026-07-31）

microCMS の MCP サーバーは接続されていないため、REST API での作成を試みたが、
`.env.local` の `MICROCMS_API_KEY` は **読み取り専用**だった。

| 操作 | 結果 |
|---|---|
| `GET /api/v1/news`（一覧・詳細取得） | ✅ 200 |
| `POST /api/v1/news`（新規作成） | ❌ 400 `POST is forbidden.` |
| `PUT /api/v1/news/{contentId}`（ID指定作成） | ❌ 400 `PUT is forbidden.` |
| `POST microcms-management.io/api/v1/media`（画像アップロード） | ❌ 403 `Forbidden` |

**API 経由で作成したい場合**は、microCMS の管理画面「サービス設定 → APIキー」で
対象キーに **POST / PUT（news）** と **メディアのアップロード権限**を付与してください。
権限を付ければ、このリポジトリの `.env.local` の値のまま自動作成できます
（キーの値をチャットに貼る必要はありません）。

### カテゴリの注意

現在 microCMS に登録されているカテゴリは **イベント / テクノロジー / 更新情報 / チュートリアル** の4つで、
「お知らせ」は存在しない。最も近い「更新情報」を推奨。

なお `types/microcms.ts` の `CATEGORY_MAP` に「更新情報」が無いため、
**一覧ページ（`/news`・TOP）では「お知らせ」と表示され、詳細ページでは「更新情報」と表示される**。
既存記事（テクノロジー）でも同じ挙動になっており、今回の追加で生じる問題ではないが、
表示を揃えたい場合は `CATEGORY_MAP` に追記するか、詳細ページ側も `toNewsItem` を通す。
