## 0. 依頼書の精査結果（着手前に検出した前提の問題）

依頼書をそのまま実行しなかった。以下3点が既存の確定方針・実測と矛盾するため、
着手前にユーザーと合意を取り直している。

### 0-1. 4日前（2026-08-12）の確定方針と正面から矛盾する

| | 08-12 確定方針（第2版） | 08-16 依頼書 |
| --- | --- | --- |
| 「新潟 システム開発」の Owner | `ai.cloudnature.jp`（想定クエリとして明記） | `/services/system-dev` |
| ai 側が狙う語 | 新潟 システム開発 ＋ 見積もり・費用・相場 | 見積もり・費用・概算系のみ |
| ai の title の「新潟のシステム開発」 | 前方一致で選ばれている理由として肯定的に記録 | 外す |

`docs/20260812_niigata_system_dev_seo_review.md` の第2版は、AI が第1版で立てた
「本体へ寄せる」方針を**前提の誤りとして訂正した文書**であり、記憶ファイル
`estimate-subdomain-is-primary-cv.md` には「`ai.cloudnature.jp` から検索露出を奪う方向の
施策を提案しないこと」と明記されている。依頼書 4（ai の title/meta から「新潟のシステム開発」を外す）は
これに該当する。

### 0-2. 依頼書の GSC データは、system-dev 改修の効果を含んでいない

`/services/system-dev` の SEO 改修（h1 を「新潟のシステム開発会社」へ、本文増強）は
**2026-08-12 に main へ投入**（`899d82b` → `5d036f7`）。
一方、依頼書の GSC データ期間は **2026-05-18〜08-14** で、89日のうち **85日は改修前**。

したがって「`/services/system-dev` が着地していない」は構造的問題の証拠ではなく、
**効果測定期間に達していないだけ**の可能性が高い。

### 0-3. 依頼書のデータは、依頼書と逆にも読める

| クエリ群 | 着地 | 平均順位 |
| --- | --- | --- |
| 新潟 システム開発 系（計83imp/3ヶ月） | `ai.cloudnature.jp/` | **17.7〜20.7位** |
| 見積もり系（計91imp/3ヶ月） | `ai.cloudnature.jp/` | **53.8〜66.6位** |

ai の title は**すでに**「見積もり」「最短1分で自動算出」を含んでいるにもかかわらず
見積もり系で 53〜66位。「新潟のシステム開発」を外せば見積もり系に集中して順位が上がる、
という仮説は現状データでは支持されない（順位が低い原因は title の焦点ではなく権威性・競合）。
一方で失うのは、非ブランド商用クエリで唯一 2ページ目に届いているポジションである。

### 0-4. 依頼書の内部矛盾

依頼書 2 は「トップの H1/title の**先頭**に『新潟 システム開発』を置け」、
依頼書 3 は「**本命 Owner は /services/system-dev**」と指示している。
トップは全ページから内部リンクが集まるドメイン最強 URL であり、同語を先頭に置けば
Google はトップを選ぶ可能性が高い。両立しない。
