### 0-2. 依頼書の GSC データは、system-dev 改修の効果を含んでいない

`/services/system-dev` の SEO 改修（h1 を「新潟のシステム開発会社」へ、本文増強）は

したがって「`/services/system-dev` が着地していない」は構造的問題の証拠ではなく、
**効果測定期間に達していないだけ**の可能性が高い。

### 0-3. 依頼書のデータは、依頼書と逆にも読める

| クエリ群 | 着地 | 平均順位 |
| --- | --- | --- |
| 新潟 システム開発 系（計83imp/3ヶ月） | `ai.cloudnature.jp/` | **17.7〜20.7位** |
| 見積もり系（計91imp/3ヶ月） | `ai.cloudnature.jp/` | **53.8〜66.6位** |

見積もり系で 53〜66位。「新潟のシステム開発」を外せば見積もり系に集中して順位が上がる、
という仮説は現状データでは支持されない（順位が低い原因は title の焦点ではなく権威性・競合）。
一方で失うのは、非ブランド商用クエリで唯一 2ページ目に届いているポジションである。

### 0-4. 依頼書の内部矛盾

依頼書 2 は「トップの H1/title の**先頭**に『新潟 システム開発』を置け」、
依頼書 3 は「**本命 Owner は /services/system-dev**」と指示している。
トップは全ページから内部リンクが集まるドメイン最強 URL であり、同語を先頭に置けば
Google はトップを選ぶ可能性が高い。両立しない。

1. **`ai.cloudnature.jp` の title / meta description / OG / keywords**（依頼書 4）
   実装しない。理由は §0-1・§0-3 のとおり。提案としては、
   「見積もり系クエリで 53.8〜66.6位という低順位の原因は title の焦点ではなく
   ドメイン権威性・競合であり、title から『新潟のシステム開発』を外しても
   見積もり系の順位が上がる根拠がない。一方で 17.7〜20.7位という
   本サイト唯一の非ブランド商用ポジションは確実に失う」。
   実施するならまず3ヶ月の GSC 実測で本体トップの立ち上がりを確認し、
   本体が同語で ai を上回ってから ai 側を調整するのが順序として安全。

   `estimate/app/layout.tsx` の `keywords` は上記1に含まれるため未着手。
   なお Google は keywords メタタグをランキングに使用していないため、
   残す／削るいずれでも順位への影響はない。

3. **canonical / noindex / 301 / URL変更 / 価格 / 外部連絡**
   依頼書が HUMAN 領域として除外。今回は必要と判断していない。

   致命的ではないが、可視 h1 が PC に無い状態は既存の構造的論点。
   今回の依頼範囲外のため未着手。
