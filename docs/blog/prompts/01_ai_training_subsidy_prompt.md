# 6. 絶対にやってはいけないこと

- 「生成AI研修なら必ず助成対象」と断定しない
- 「最大75%」「自己負担10万円」等の割合・金額を、対象条件を確認せず一般化しない
- 新潟AIアカデミーの研修が助成対象になると保証しない
- 受給を保証しない
- 制度名、コース名、助成率、対象者、申請期限を記憶だけで書かない
- **雇用関係助成金の申請代行は社会保険労務士の独占業務。** 行政書士を申請代行者として案内しない
- 「補助金」と「助成金」を同義として雑に扱わない（検索語として補助金が使われる点を説明するのは可）
- AIが作った架空の研修実績、利用企業、採択事例を作らない

# 7. この記事の差別化の中心 ★最重要

**様式第28号（受講料等の価格設定に関する疎明書）をAI研修の文脈で解説することが、この記事の最大の差別化要素。**

制度概要だけを書いた記事は既に大量に存在する。勝ち筋は「AI研修という商材で、この改正が実務上どう効くか」を書けること。

書くべき論点（公式資料で裏付けが取れる範囲で）:
- 受講料が市場価格から見て妥当かを説明する書類であること
- 対象外講座の費用が混ざっていないかが見られること
- 助成対象者数に対して過大な契約になっていないかが見られること
- **AI研修で特に問題になりやすい契約形態**
  - 定額制のオンライン学習サービス
  - 生成AI講座のパック契約
  - 複数拠点で使う法人契約
  - 人数区分の差額部分が助成対象外になり得るケース

これらは公式パンフレット・支給要領に例示があるかを確認したうえで書く。確認できない例は作らない。
「支給申請の細かな判断は労働局の確認事項」であることを明記する。

# 8. E-E-A-Tの入れ方

肩書きを並べるだけにしない。以下を本文中に自然に入れる。

- 現役エンジニアとして「研修で教えた内容を実務でどう使うか」という視点
- 研修をツールの操作説明だけで終わらせず、要件定義・検証・セキュリティまで扱う理由
- 助成金適用可否を考えるとき、研修時間だけでなく「職務との関連」「訓練内容」「実施形態」「申請時期」等を確認すべきという実務視点
- 制度上不明な点は「**管轄労働局または社会保険労務士へ確認**」と明記

自社の研修実績・アンケート数値は `00` に記載された範囲のみ使用する。
企業名非公開の場合は「県内IT企業」「製造業」等、`00` で確認できる粒度に限定する。

# 9. 推奨構成

## 導入
- 「AI研修に助成金は使えるのか」の答えを最初に提示
- 結論は「条件を満たす研修であれば人材開発支援助成金の対象になり得る。ただし研修内容、対象者、実施方法、申請手続き等で判定される」
- 2026年度の情報であることと、最終判断は公式情報で確認する旨を明示

## H2 生成AI研修で検討できる人材開発支援助成金とは
- 制度の目的
- AI研修で候補になり得るコースを公式情報に基づいて整理
- 関係が薄いコースまで水増ししない

## H2 どのようなAI研修が対象になり得るか
- 職務との関連性／OFF-JT等の扱い
- 訓練時間・形式・講師等の要件は現行資料を確認して記載
- 「○時間以上なら必ず対象」と単純化しない

## H2 2026年度に確認しておきたい制度変更 ★差別化パート
- 様式第28号の解説（§7参照）
- なぜ価格設定の疎明が必要になったかは、公式資料に理由が明示されている場合のみ説明

## H2 申請から受給までの流れ
訓練計画 → 事前手続き → 研修実施 → 支給申請 → 必要書類 → 申請期限
すべて公式一次情報を根拠にする。

## H2 対象外・不支給になり得るケース
公式要件に反するケースのみ。誇張しない。

## H2 AI研修を選ぶときに助成率だけで決めない
研修の目的／自社業務を題材にできるか／研修後に現場で使える成果物が残るか／セキュリティ・検証まで扱うか／研修後の支援

## H2 新潟AIアカデミーの開発内製化プログラム
- 宣伝色を抑える
- 「AIの使い方」だけでなく、自社業務を題材に要件定義→実装→検証まで扱うという違いを説明
- 助成金適用を保証しない
- 相談時に研修内容と制度要件を照合する、というCTAにする
- LPへ内部リンク

## H2 よくある質問
- ChatGPTの使い方研修でも対象になりますか
- オンライン研修でも対象ですか
- 経営者本人も対象ですか
- 研修を始めてから申請できますか
- 新潟県以外の企業でも利用できますか
- 社内研修でも対象になりますか

FAQは公式情報で答えられるものだけ回答する。
