# 5. 検索意図

「AIで見積書を書かせるプロンプト」を探している人だけを対象にしない。検索者には3段階ある。

1. WordやExcelの見積書文章を生成AIで作りたい
2. 過去見積や単価表を参照して金額計算まで半自動化したい
3. ヒアリングから見積提示までシステムとして自動化したい

記事ではこの3段階を整理し、「生成AIに文章を書かせること」と「見積ロジックそのものを自動化すること」は**別**だと説明する。

# 8. 技術的な正確性

AI見積もりを説明するときは以下を分ける。

文章生成 ／ 必要項目のヒアリング ／ 過去データ・単価マスタの参照 ／ ルールベース計算 ／ LLMによる要件分類や提案 ／ 金額算出 ／ 承認フロー ／ PDF・メール等の後処理

- 「AIがすべて勝手に正しい金額を決める」と書かない
- 金額の確定には、単価マスタ、計算ルール、制約条件、人間承認など**決定論的な要素**が重要であることを説明する
- RAG、function calling、workflow、AI agent 等の用語を使う場合は、製品公式ドキュメントまたは一次情報で定義を確認する
- **RAG（外部データの参照）とモデル学習を混同しない**

# 9. E-E-A-Tの入れ方

「実際に自社で作ったから分かる」を具体的に見せる。

- なぜ自由入力だけでは見積精度が安定しないのか
- なぜ質問を段階化するのか
- なぜAIの自由生成だけで金額を決めず、価格モデルや補正係数を併用するのか
- 見積もり自動化に向く業務・向かない業務
- どの段階で人間承認を残すべきか
- 単価表や過去見積が汚い場合に最初に何を整えるか

`00` の「約10件のシステム開発実績」は、**業務システム設計の経験**の裏付けとして使う。
そこから導ける独自視点は「見積もり自動化もAIモデル単体では完結せず、業務フロー・マスタ・例外処理・権限・既存システム連携まで設計する必要がある」という点。

### 絶対に誤認させないこと

会計・交通費管理・予約・オンライン診療の4例は**AI見積もりシステムの導入実績ではない**。

禁止例:
- 「AI見積もりを約10件導入した」
- 「大手カメラ企業でAI見積もりを導入した」
- 「医療・宿泊業で見積もりAIが稼働している」

経験していない具体的失敗談を作らない。

# 10. 推奨構成

## 導入
- AIで見積書の文面を作るだけなら簡単
- しかし企業が本当に欲しいのは「要件整理→価格計算→承認→見積書発行」までの再現可能な仕組み
- 本記事では自社でAI見積もりシステムを開発した経験をもとに、どこまで自動化できるかを説明する

## H2 AIで見積もり作成はどこまで自動化できるか
表で3段階に分ける。
- レベル1: 文面・見積書テンプレート生成
- レベル2: 過去見積・単価データ参照＋候補金額提示
- レベル3: ヒアリング→計算→承認→発行までワークフロー化

## H2 見積もり業務が属人化する理由
過去見積の検索／顧客要件の読み替え／単価・原価・工数の判断／例外処理／担当者しか知らない補正ルール

## H2 AI見積もりシステムの基本構成
図解できる粒度で:
顧客入力 → 要件整理 → データ・価格マスタ参照 → ルール計算 → AIによる分類・提案 → 人間確認 → 見積書生成 → CRM / メール等へ連携

特定ベンダー製品に依存しすぎず、一般構造として説明。

## H2 AIに任せてよい範囲・人が確認すべき範囲
- 文章整形、分類、候補提示はAIに向く
- 最終価格、契約条件、重大な例外は人間承認を残す
- ただし業務によって異なる

## H2 自社開発したAI見積もりシステムではどう設計したか ★E-E-A-Tの中心
§6の確認済み仕様を使用。なぜこの構成にしたのかを、確認できる範囲で説明する。
理由が不明なら勝手に作らず、単に仕様として記述する。

## H2 AI見積もり導入に必要なデータ
商品・サービスマスタ／単価表／過去見積／工数実績／値引き・補正ルール／例外条件
データがなくても始められる場合と、データ整備が必要な場合を分ける。

## H2 SaaS・Excel/生成AI・個別開発のどれを選ぶか
比較表: 初期費用／導入速度／カスタマイズ／既存システム連携／見積ロジックの複雑さ／運用保守
具体料金は最新の客観情報がない限り出さない。

## H2 AI見積もりが向かないケース ★必須
- 毎回完全オーダーメイドで価格決定ルールが存在しない
- 見積前に現地調査等が不可欠
- 価格マスタ・原価情報が全く整備されていない
- 法的・安全上、人の専門判断が不可欠

**「向かない」を書くことで営業記事ではなく判断記事になる。ここを削らないこと。**
