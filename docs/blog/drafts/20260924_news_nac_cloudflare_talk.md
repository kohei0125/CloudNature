## content（HTML／microCMS のリッチエディタに貼り付け）

### 入稿方法（重要）

**microCMS のリッチエディタには HTML ソース編集モードが存在しない。** 管理画面から HTML を貼っても、
タグはプレーンテキスト（またはコードブロック）として保存され、公開ページに `<p>` や `<h2>` が文字のまま出る。
公式ドキュメントも「Word 文書や HTML データを貼り付けた場合、入稿内容が全て正しく保存されることは保証していない」と明記している。

**HTML で入稿する正規の手段は WRITE API のみ**（[リッチエディタのWRITE API](https://document.microcms.io/manual/rich-editor-write-api)）。
リッチエディタが対応するタグ（h1-h5 / p / br / strong / em / u / s / ul / ol / table / blockquote / hr / pre・code / img / figure / a）の範囲内であれば、
HTML 文字列を送るとエディタの構造にパースされる。見出しの `id` は microCMS 側で自動付与される。

#### 手順

1. microCMS 管理画面 → サービス設定 → API キー → 対象キーに **`news` の PATCH 権限**を付与
   - 権限は「デフォルト権限」（サービス全体）と「個別権限」（API ごと）の2階層。`news` の個別権限が存在する場合はそちらが優先されるため、**個別権限の行の PATCH** を有効にする
   - 作業が終わったら PATCH 権限は外す
2. HTML を**改行なしの1行**にする（WRITE API は改行を含めないことが前提）
3. 送信（`content` のみ更新する PATCH）

```bash
set -a && . ./.env.local && set +a
python3 -c "import json;html=open('content_oneline.html',encoding='utf-8').read().strip();json.dump({'content':html},open('patch.json','w',encoding='utf-8'),ensure_ascii=False)"
curl -X PATCH -H "X-MICROCMS-API-KEY: $MICROCMS_API_KEY" -H "Content-Type: application/json" \
  --data-binary @patch.json \
  "https://$MICROCMS_SERVICE_DOMAIN.microcms.io/api/v1/news/<contentId>"
```

4. 確認：GET し直して `content` が `<p>` の実タグになっているか（`&lt;p&gt;` や `<pre><code>` になっていないか）を見る
5. 公開ページへの反映は ISR で最大60秒待つ

内部リンクは microCMS 側のパースを確実にするため**絶対 URL**（`https://cloudnature.jp/...`）で書く。
